# Coffee Katta Brand Guidelines & Mascot Rules

## Official Mascot & Header Logo
- In the top header / branding section across ALL screens:
  - **Mascot Logo**: ALWAYS use the official **Bearded Man icon** (`assets/branding/app_icon.png`) inside a circular avatar container.
  - **Never use generic coffee cup icons** (`Icons.coffee_rounded`, `Icons.local_cafe_rounded`) as the primary brand logo.
  - Use the reusable component [`CoffeeKattaBrandBadge`](file:///e:/projects/New%20folder/ShreeRajmandir-change%20to%20coffe%20katta/lib/presentation/widgets/global/coffee_katta_brand_badge.dart).
